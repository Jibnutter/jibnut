# Jibnut

A slopestyle skiing and snowboarding game for the browser, built with
three.js and Rapier physics.

**Play it:** https://jibnutter.github.io/jibnut/

## Develop

```sh
npm install
npm run dev     # local dev server
npm run build   # production build into dist/
```

Pushing to `master` builds and publishes the game to GitHub Pages.
